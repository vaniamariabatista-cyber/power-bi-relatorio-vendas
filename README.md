# Relatório de Vendas com Power BI

Projeto do desafio da trilha de Power BI (Bootcamp Universia 2026 / DIO), construído a partir da base Financial Sample.

## Estrutura
- **Página 1 – Produtos e Segmento**
- **Página 2 – Países e Lucro**: alternador Pizza/Colunas com indicadores (bookmarks)
- **Página 3 – Mapas e Lucro**

## Recursos utilizados
- Layout com título e cabeçalho
- Botões de navegação entre páginas (Page navigator)
- Segmentadores de Year e Product
- Botões com indicadores para alternar visuais sobre o mesmo assunto
- Cartões, gráficos de colunas, pizza e mapa
